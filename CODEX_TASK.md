# Задача для Codex

Работай с GitHub-репозиторием `ponomander-cloud/tickets`.

В этой локальной папке лежит готовая реализация. Нужно:

1. Проверить код `fetch_rzd.py` и workflow `.github/workflows/fetch-rzd.yml`.
2. Убедиться, что поиск использует `rzd-api==3.0.0` и получает данные непосредственно с `ticket.rzd.ru`.
3. Нас интересуют **ТОЛЬКО билеты в купе**.
4. На каждый день диапазона в `request.json` сохранить до 3 самых дешёвых вариантов купе со следующими полями:
   - дата;
   - номер поезда;
   - цена;
   - время отправления;
   - время прибытия;
   - длительность пути;
   - количество доступных мест.
5. В конце сформировать `overall_top` — 10 самых дешёвых вариантов купе по всему диапазону.
6. Залить содержимое ЭТОЙ папки в корень репозитория `ponomander-cloud/tickets` (не создавать дополнительную вложенную папку).
7. Запустить GitHub Action `Fetch live RZD coupe prices`.
8. Если workflow упадёт — изучить логи, исправить код и повторять до рабочего результата либо до подтверждённой внешней блокировки RZD со стороны GitHub Actions.
9. Проверить, что появился `data/latest.json`, и кратко сообщить мне:
   - сработал ли запрос;
   - сколько дней обработано;
   - есть ли купе;
   - 3 самых дешёвых варианта из `overall_top`.
